PAKAI PAKET INI

1. Upload index.html, style.css, script.js ke root repository GitHub Pages.
2. Buka Google Spreadsheet tujuan -> Ekstensi -> Apps Script.
3. Di Code.gs hapus kode lama, tempel Code.gs dari paket ini, lalu Save.
4. Deploy -> Manage deployments -> Edit deployment -> Deploy.
   Execute as: Me
   Who has access: Anyone
5. URL web app sudah tertanam di script.js sesuai URL yang kamu berikan.
6. Nama tab spreadsheet harus Sheet1.
7. Website memakai kuota 50 motor dan field Email, Nama, Merk/Tipe, Nopol, Atas Nama STNK.
8. Jangan membuat deployment baru jika ingin URL /exec tetap sama; edit deployment yang ada.

Google menyatakan deployment versi perlu diperbarui ke versi baru saat kode web app berubah. Lihat dokumentasi Apps Script deployment resmi Google.
